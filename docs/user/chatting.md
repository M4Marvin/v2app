# Chatting

The chat screen is where you talk to your characters. It's a full-screen view with a blurred backdrop and glassy message bubbles. This page covers everything you can do there.

## Start a chat

When you click **Start Chat**, the character's greeting is the first message. If the card has several greetings, they're swipeable. A counter like 1/3 shows how many there are.

## The composer

The composer is the bar at the bottom. Type a message and press **Enter** to send it. While the AI is typing, press **Enter** to stop it. **Shift+Enter** inserts a line break instead of sending. Replies stream in live as the AI writes them. From the chat header you can toggle the **Portrait** and **Scene** panels on and off.

## Swipe

Under an AI message you'll find left and right chevron buttons. Click them to see alternate replies. A counter like 2/3 shows where you are. Swiping creates a branch, which is an alternate path in the conversation. You can move back and forth between alternate replies freely, and nothing is ever lost. Think of the conversation as a tree. Every swipe grows a new branch, and you can climb back and take a different one.

## Regenerate

A circular-arrow button sits on the last AI message. It appears only when there are no more stored alternatives. Click it to ask the AI for a brand-new reply.

## Edit

To change a message:

1. Hover over the message and click the pencil icon.
2. Type your changes.
3. Click **Save** (or press **Ctrl/Cmd+Enter**) to keep them, or **Cancel** (or **Esc**) to discard.

Editing rewrites just that message; the rest of the conversation stays.

## Delete

Hover over a message and click the trash icon. A confirmation dialog says: "This deletes this message and all messages after it. This cannot be undone." Deleting removes that message and the whole branch after it.

## Impersonate

To have the AI write as you:

1. Click the **wand** icon in the composer.
2. Review the draft the AI puts in the input box, and edit it if you like.
3. Press **Enter** to send it.

You need at least one of your own messages in the chat first.

## Continue

With the input box empty, press **Enter** or click the send arrow. The AI continues the scene. If the last message was the AI's, it produces a new alternative branch.

## Markdown

Messages support simple formatting: **bold**, *italic*, code blocks, images, and tables. Code blocks get a **Copy** button. Dialogue in quotation marks gets a highlight color automatically.

## Keyboard shortcuts

| Shortcut | Action |
|---|---|
| **Enter** | Send, or stop while the AI is typing |
| **Shift+Enter** | Insert a line break |
| **Ctrl/Cmd+Enter** | Save an edit |
| **Esc** | Cancel an edit |
| **Ctrl+K** | Open the command menu |
| **/** | Focus the search box on the Characters page |
